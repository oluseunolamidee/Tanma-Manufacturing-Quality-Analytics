# Tanma-Manufacturing-Quality-Analytics
Manufacturing quality analytics project using Excel, SQL and Power BI to evaluate QC performance, complaints and operational efficiency.

Overview

TANMA Manufacturing Quality Analytics is a simulated manufacturing analytics project designed to evaluate quality-control performance and operational efficiency within a beverage manufacturing environment.

The project demonstrates how operational and quality data can be transformed into actionable performance indicators using Excel, SQL, and Power BI.

Note: The dataset used in this project is synthetic and was created for portfolio and analytical demonstration purposes.

🎯Business Problem

Manufacturing organizations generate large volumes of quality and operational data. Without effective analysis, important signals such as recurring complaints, delayed responses, poor defect detection, and differences in performance between production lines can be difficult to identify.

This project explores how a centralized quality analytics approach can help management monitor performance and identify areas requiring improvement.

❓ Key Questions

The analysis focuses on questions such as:

How effectively are quality issues being detected?

How quickly are quality-related issues being responded to?

How efficiently are issues being resolved?

What proportion of quality problems escape detection before reaching the next stage or customer?

How does QC competency vary across production lines?

Which operational areas may require further investigation or improvement?

📊 Key Performance Indicators

The project evaluates several quality and operational indicators, including:

Detection Rate:	Measures the proportion of quality issues detected through QC processes

Average Response Time:	Measures how quickly quality issues receive a response

Resolution Efficiency:	Evaluates the effectiveness and speed of issue resolution

Complaint Escape Rate:	Measures issues that escape internal quality controls

QC Competency Score:	Provides a performance measure of QC competency across production lines
